# 华佗五禽戏 · 手势动捕原型

这是一个无需安装依赖的浏览器端原型。它使用 MediaPipe Gesture Recognizer 在本地摄像头画面中追踪 21 个手部关键点，并在识别到稳定握拳后进入加载界面。

## 启动

在 Windows 中双击 `打开五禽戏.cmd`，会自动启动本地页面服务并打开浏览器。此方式只使用 Windows 自带的 PowerShell，关闭 Codex 后也可使用。服务意外关闭后，可再次双击此文件。

也可以在本目录打开 PowerShell：

```powershell
node .\server.mjs
```

然后访问：

```text
http://localhost:4173
```

首次打开时允许浏览器使用摄像头。模型文件与运行库会从 Google/JSDelivr 加载，首次运行需要联网；手部图像不会上传，由浏览器本地处理。

## 当前交互

1. 摄像头检测到手后显示 21 点骨架。
2. 完全握拳且识别置信度不低于 `0.68` 时开始计时。
3. 稳定保持 `650ms` 后触发水墨转场。
4. 自动进入加载界面，毛笔进度条从 0% 运行约 `4.6s`。
5. 加载界面中张开手掌稍停后快速左滑可返回首页；左上角“返回”仍可用鼠标点击。
6. 加载达到 100% 后自动进入五禽戏徽章选择页。页面起初近乎全黑，张开手掌可移动简约光点，照亮附近一小片画面；触及虎、鹿、熊、猿、鸟任一徽章时对应徽章高亮。无摄像头时也可用鼠标预览光照效果。
7. 每个页面都保留手部动捕预览。徽章选择页在可学习的徽章上握拳时，光标和预览窗会同步显示确认进度；张掌稍停后左滑可返回首页。
8. 在虎戏、鸟戏或鹿戏徽章上握拳进入对应的动作学习页，从第 1 步开始。页面上方提示“张掌左滑后退 · 握拳前进”，底部按钮显示“握拳前进”，第 5 步显示“握拳完成”。张掌稍停后快速左滑退回上一步，第 1 步左滑退回五禽选择。对准右侧步骤握拳可直接选择；画面上的返回按钮仍可用鼠标点击。第 5 步握拳完成后返回五禽选择。
9. 鸟戏徽章使用同一套交互，从准备站立、两臂侧展、舒展上举、提膝平衡到落臂还原，共 5 步。
10. 鹿戏徽章使用同一套交互，从左脚上步、重心前移、立身画弧、转腰下势到两臂转动，共 5 步。

主要参数位于 `app.js` 顶部，可调整识别阈值、保持时间、抗闪烁时间和推理频率。
